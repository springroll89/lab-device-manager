# TYD02 注射泵 实时监控与记录台 — Phase-1 设计

- **日期**: 2026-06-30
- **设备**: Leadfluid 雷弗 TYD02 实验室注射泵（RS485 / Modbus RTU）
- **状态**: 已与用户确认（2026-06-30）
- **关联**: 协议 `注射泵/注射泵RS485通讯协议标准.pdf`、说明书 `注射泵/TYD02注射泵说明书.md`、已验证脚本 `注射泵/modbus_probe.py`

## 1. 目标

为本批次仪器调试提供「实时读取与记录」能力。Phase-1 以注射泵为首个落地对象，建立一套**可复用于搅拌器、粘度计等后续仪器**的本地监控+记录架构。

核心：泵接到电脑后，实验全程状态可实时读取、实时展示、自动落盘记录，满足事后分析与研发数据留档。

## 2. 范围

**In（Phase-1）**
- 只读：Modbus RTU 周期读取泵状态
- 实时网页面板展示（状态/液量/时间/流速/温度/进度/报警）
- 自动 CSV 记录 + 会话管理（开始/停止记录、备注、导出）
- 报警高亮与错误码记录
- 连接状态监控（串口在线/通讯中断）

**Out（不在 Phase-1）**
- 任何写入/控制泵（启停、设流速、改模式）→ Phase-2
- 流量校正向导、多通道（-02/-04/-10）分通道
- 联网/多用户/云端、Wi-Fi/App 远控

> ⚠️ 关键约束：**Phase-1 纯只读**。「开始/停止记录」只控制日志，不控制泵；泵的启停仍用泵自己的面板。代码层面不接入任何写指令（FC 0x06/0x10/0x05/0x0F）。

## 3. 假设与约束

- **环境**：单台 macOS 工位机，单用户，`localhost`。
- **链路**：宇泰 UT-885 USB↔RS485（FTDI FT232R），`/dev/cu.usbserial-BG039GXP`（FTDI 序列号 `BG039GXP`；换线会变 → 走配置）。
- **串口参数**：`9600, 8E1`（偶校验），从机地址 `1`，Modbus RTU，CRC-16 低字节在前。**即泵出厂默认，无需改泵设置。**
- **用户**：现场操作员技术水平偏低；开发者运维经验有限 → 部署须「一条命令运行」、依赖尽量少、离线可用。
- **研发数据**：实验数据需可靠留存、可追溯、可备份（可复现）。

## 4. 架构与数据流

```
TYD02 ─RS485─ UT-885 ─USB─ Mac
                          │
            ┌─────────────┴──────────────┐
            │  后台采样线程 (默认每 1s)     │
            │  Modbus 层 (8E1 / CRC)       │  ← 复用已验证的 modbus_probe.py
            │  → PumpStatus (不可变快照)   │
            └─────┬───────────────┬───────┘
                  │               │
            ┌─────▼──────┐   ┌────▼──────────────┐
            │ 会话记录器   │   │ Flask + SSE        │
            │ (CSV 落盘)  │   │ → 浏览器实时面板    │
            └─────────────┘   └────────────────────┘
```

采样线程产出 `PumpStatus` 不可变快照，分发给「记录器（落盘）」与「Web 服务（SSE 推送）」两个订阅者，互不阻塞。

## 5. 组件 / 文件结构

| 文件 | 职责 |

## 6. 数据模型

### 6.1 PumpStatus（每次采样的不可变快照）

`timestamp, state(运行/暂停/停止/报警), work_mode, flow_rpm, acc_volume, acc_unit, consumed_volume, consumed_unit, remaining_volume, remaining_unit, elapsed_ms, remaining_ms, cycles, progress_pct, temp_c, alarm, error_code, device_id`

### 6.2 寄存器映射（全部只读）

| 字段 | 寄存器 | 功能码 | 类型 | 说明 |
|---|---|---|---|---|
| 运行状态 | 4126 / 4024 / 4025 / 1047 | 0x03 / 0x04 | U16 | 运行/暂停/停止/报警，组合推导 |
| 工作模式 | 4017 | 0x03 | U16 | 仅注入0…连续4 |
| 累计液量 | 1032 + 1034 | 0x04 | Float + U16 | 值 + 单位 |
| 已输送液量 | 1035 + 1037 | 0x04 | Float + U16 | 消耗液量 |
| 剩余液量 | 1038 + 1040 | 0x04 | Float + U16 | |
| 注入流速 | 1002 | 0x04 | Float | rpm |
| 抽取流速 | 1041 | 0x04 | Float | rpm |
| 已用时间 | 1043 | 0x04 | U32 | 毫秒 |
| 剩余时间 | 1045 | 0x04 | U32 | 毫秒 |
| 已完成循环 | 1012 | 0x04 | U32 | |
| 进度 | 1004 / 1006 | 0x04 | U32 | 当前步/所需步 → 百分比 |
| 内部温度 | 1000 | 0x04 | S16 | ℃ |
| 报警/错误 | 1047 / 1980 | 0x04 | U16 | 报警标志 / 20 条错误列表 |
| 设备身份 | 1018 / 1023 | 0x04 | ASCII | LeadFluid / TYD02（开机读一次） |

### 6.3 字节序与单位

- **ASCII 字符串寄存器**（1018/1023）：按 16 位小端存放，每对字节需交换（已验证：`65 4c...` → `LeadFluid`）。
- **Float / U32**：字节顺序由泵「字节顺序 CDAB/ABCD」设置决定 → **启动时自动探测**（对已知量程寄存器取落在合理范围的解码）。
- **温度(1000)**：Signed Short，已验证大端。
- 单位码：体积 `0=纳升 1=微升 2=毫升 3=升`；时间寄存器为毫秒；转速为 rpm（**phase-1 显示 rpm 并标注**；换算成 mL/min 需注射器内径，留待后续）。

### 6.4 CSV 会话格式

- 一段记录 = 一个文件：`session_YYYYMMDD_HHMMSS_<实验名>.csv`
- 首部写元信息（实验名/操作人/批次/设备ID/起止时间/泵型号），其后**每秒一行**（字段 = 6.1 全部）。
- **追加写 + 定时 flush**，断电不丢已采数据；**只新增不改旧文件**。
- 单位随行存储（操作员中途切单位也正确）。
- 日志目录可配；定期备份（备份策略后续补）。

## 8. 错误处理与安全

- 读超时 / CRC 错 → 跳过该秒、错误计数、面板标「通讯中断」并保留上一次值（灰显）。
- 串口消失（拔线）→ 报警 + 自动尝试重连。
- 泵报警（堵车等）→ 面板变色 + 弹提示 + 记录错误码与时刻。
- **Phase-1 不存在任何写路径**（代码不接入写指令）。

## 9. 测试策略

- **单元**：CRC、寄存器解码（ABCD/CDAB 两种字节序）、单位换算、状态推导、CSV 写入。
- **集成**：用「录制的 Modbus 帧」回放做假泵（mock serial），不打扰真设备。
- **现场链路**：复用 `modbus_probe.py` 已验证。
- 目标覆盖率 ≥80%（遵循通用测试规范）。

## 10. 运行与部署

- `python web/app.py` → 自动开浏览器 `http://localhost:7800`。
- 离线：Chart.js 本地打包，不用 CDN。
- 换仪器：改 `config.toml` + 增加一个 `InstrumentAdapter` 实现。

## 11. 可扩展性（多仪器）

定义 `InstrumentAdapter` 接口（`read_status() → StatusSnapshot`、`identity()`）。泵为首个实现；搅拌器（RS232+Modbus 保持寄存器）、粘度计待其线缆到位后照此实现。Web 面板以「设备 tab」方式扩展。

## 12. Phase-2 预留

- 写入/控制：启停（4126/4025）、设流速（4015）、工作模式（4017）、参数锁定等。
- 所有写操作需**二次确认 + 审计日志**（受控设备，参见数字孪生正本/电子副本规则）。
- 流量校正向导、多通道。

## 13. 假设（待实现期验证）

- 浮点字节序默认按 CDAB/ABCD 自动探测结果采用。
- 状态推导规则（运行/暂停/停止/报警）需在真机上用 4126/4024/4025/1047 组合校准一次。
- 采样间隔 1s 足够；如需更快（0.5s）须验证 RS485 总线负载。
- 本机单用户；Flask 开发服务器即可，不做生产级并发。
