## 1. 固定输出区块

| 报告区块 | 电子记录来源 | 必填/缺口策略 |
|---|---|---|
| 批次与版本 | `experiment` | Batch ID、体系、配方、SOP、目标粘度、操作/复核人、快照 SHA-256 必须存在 |
| 配方参数 | `recipe_parameter` | 一行一个参数；未录入时显示空表，不从自由文本猜值 |
| 环境、设备与器皿 | R201-01、R201-02 `step_instance.result_json` + 数据源绑定 | 人工确认和设备原始数据分别展示 |
| 物料使用 | `material_usage` | 名称、批号、实际量、单位必填；有效期、理论量、外观缺失时显示 `—` |
| 酸水配制 | R201-04 结果与事件 | 保存 C1、C2、V1、V2 和“酸入水”确认；计算不一致不得静默修正 |
| 阶段执行 | `step_instance` + `experiment_event` | 显示有效起止时间、状态、结果摘要和时钟可信状态 |
| 温度与加酸数据 | `experiment_data_source_binding` + `sample` | 必须显示设备、指标/通道、绑定窗口；禁止用未绑定平均温度代替反应温度 |
| 粘度监测 | `measurement` | 显示粘度、扭矩、温度、转子/转速、有效性、样本引用和来源 |
| 出料与转序 | R201-60、R201-70 结果 | 室温确认、过滤、皮重/总重、转序粘度、外观、标签和下一工序 |
| 偏差与审计 | `deviation` + `experiment_event` | 原始值不覆盖；显示偏差状态、有效时间、接收时间、操作者和幂等键证据 |
| 复核与结论 | `experiment` + 复核事件 | MVP 固定标识 `parallel_validation`；正式放行仍以受控纸质签名为准 |

## 3. 数据完整性口径

- 报告只把 `device_role=reaction_temp` 且明确 `metric_key/channel_selector` 的样本画入反应温度曲线。
- `run_id` 可为空；绑定窗口仍由 `linked_at_ms/unlinked_at_ms` 限定。
- 若批次参数快照配置 `telemetry_gap_threshold_ms`，相邻样本间隔超过阈值即列为缺口；未配置时明确显示 `threshold_not_configured`。
- 20 分钟检查点是 `aging_temperature_checkpoint` 派生事件，保存到期时间、样本时间、样本 ID、设备 ID、指标键和值。
- 粘度终点只使用有效测量：扭矩 10%–90%，最近连续两次位于目标区间且差值不超过 0.5 mPa·s。

## 4. 尚需批准后才能解除的限制

- 唯一用户身份、角色、重新认证和合规电子签名尚未实现。
- C-001 至 C-018 的未决工艺参数不得由本报告默认值替代。
- 方瑞粘度计校验和、扭矩缩放和原始帧真机验证未关闭前，自动读数仍需受控人工确认。
- 当前按“一台设备一个串口”运行；HMS-C 共享 RS485 多从机调度未启用。
- 本映射是 V1 软件验收基线，不是质量体系批准文件。
