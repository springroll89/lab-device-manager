# 危化品管理：国家要求与系统现状对照

> 用途：作为 Lab Device Manager 危化品管理能力的合规参照与差距分析底稿。
> 范围：中国境内化学/陶瓷膜研发实验室的危险化学品（含剧毒、易制爆、易制毒）全生命周期管理。
> 核验日期：2026-07-25。现行上位法为 2026-05-01 起施行的《中华人民共和国危险化学品安全法》。
> 标注：🔒 = 法规强制　✅ = 行业最佳实践/单位可加严

## 二、全生命周期（真实流程）

```
合作高校采购 → 交接验收入库 → 储存保管 → 领用使用 → 退库/废弃物 → 应急
        ↑____________全流程台账 + 二维码追溯____________↓
```

- **采购（系统外）**：由合作高校及其采购流程负责；本系统不做采购申请、比价、审批或下单。
- **交接验收入库**：核对来源单位、交付/领用凭证、品名/CAS/批号/数量/包装完好 → 关联来源方许可/备案凭证（如适用）→ 核供应商 SDS → 登记入台账 → 贴内部码。
- **储存**：按类别**分柜**（防火柜/酸碱柜/通风柜），禁忌品隔离，温控通风，防泄漏托盘；剧毒、易制爆进双人双锁柜。
- **领用**：审批 → **最小量原则**（只领本次用量）→ 记录领用人/量/用途 → 对剧毒、重大危险源、药品类易制毒以及单位明确加严的物料实行双人确认。
- **使用**：通风橱内操作，配 PPE，按 SOP；现场只保留最小暂存量。
- **废弃物**：废液/固废**分类收集**（有机/无机/含卤/不含卤）→ 暂存柜 → 有资质单位处置 → 联单。
- **应急**：洗眼器/紧急淋浴、泄漏应急包、灭火器材、应急预案；SDS 一键可查。

## 三、核心原则（管理上的硬规矩）

1. **禁忌混存（最高安全风险）** —— 放错柜子会爆炸/起火。专业实验室都有一张**兼容性矩阵**（氧化剂 ≠ 还原剂/易燃；酸 ≠ 碱；剧毒单独）。
2. **双人控制边界要准确** —— 国家层面的通用强制范围是剧毒和构成重大危险源的其他危化品；药品类易制毒另有双人双锁专门规定。易制爆、易制毒可按地方公安或单位制度加严，但系统必须记录“法定依据/内部加严原因”，不能一刀切。
3. **最小化** —— 只买、只领、只暂存必要的量。
4. **先进先出（FIFO）** —— 防止积压过期。
5. **一物一码、全程可追溯** —— 每个容器从入库到处置/废弃全链路留痕。
6. **SDS 现场随时可查** —— 应急时几秒内能看到处置方法。

## 四、信息化系统通常做的事

成熟的实验室危化品管理系统一般覆盖：

- 试剂电子台账 + **每瓶二维码**（本系统已有 `PC-xxxx`）。
- **在线 SDS 库** + CAS 自动带出危险性（本系统已接 PubChem ✅）。
- **储位管理 + 兼容性校验**（入库/移库时检查"这个柜子能不能放这类"）。
- **双人流程电子化**（在法律、地方公安或单位制度要求的范围内，由两个不同账号完成申请和复核；电子确认不能替代实体双锁）。
- **领用审批流**（线上审批 + 用途）。
- **库存预警**：低库存 / 过期 / 临期（本系统已有 ✅）。
- **危废模块**：分类、暂存、联单、处置记录。
- **盘点**：扫码盘库，账物核对。
- **应急看板**：按柜/按类别一键列出存量和 SDS。
- **报表/监管台账**：一键导出给检查。

## 五、对照本系统：哪些有、哪些是缺口

### 已经做得不错的 ✅
一物一码 `PC-xxxx`、PubChem 自动出危险性/SDS、状态硬闸（隔离/处置/过期/空瓶不能领用投料）、权限分级、全流程流水审计、库存预警、危险性统计看板。在国内中小实验室里，这套底子靠前。

### 真正的缺口（按风险/合规优先级排）⚠️

| 优先级 | 缺口 | 说明 | 严重性 |
|---|---|---|---|
| **已实现** | **禁忌混存校验** | 库位配置允许储存组和物理防护；新建、编辑、领用和实验投料都会检查库位允许范围及现存禁忌组，冲突时硬性阻断。 | 安全/🔒 |
| **已实现** | **双人电子确认** | 对剧毒、重大危险源、药品类易制毒以及单位明确加严的物料启用两个不同账号确认，操作流水保存申请人与第二确认人；实体双锁仍需线下落实。 | 合规/🔒 |
| **已实现** | **危化资料操作闸** | 目录判定、供应商 SDS 核验、储存组、合规库位或管制品交接凭证不完整时，禁止领用和实验直接扣料。 | 安全 |
| **已实现** | **危废模块** | 独立记录危废容器、分类/代码、危险特性、成分、暂存库位、加入、封口、国家电子联单编号、承运和处置资质及完成转移。 | 合规/🔒 |
| **已实现** | **目录辅助判定** | 内置官方《危险化学品目录（2015版）》及 2022 年柴油调整，按 CAS 辅助匹配；CAS 未匹配仍强制人工法规复核，避免误判为安全。 | 合规 |
| **已实现** | **合作渠道交接入库** | 不建设采购审批模块；记录合作高校/交付单位、交付或领用凭证、接收日期、接收人、验收人及来源方许可/备案凭证（如适用）。 | 追溯 |
| **P2** | **领用量 vs 实际用量追溯** | 实验里扣的是"确认用量"，但领出量/退回量的闭环可以再紧。 | 台账 |
| **已实现** | **SDS 应急入口** | 物料详情提供醒目的供应商 SDS 入口；供应商 SDS 未核验时不能领用目录危化品。 | 实用 |
| **系统外** | **许可、公安报送与实体设施** | 采购许可、公安信息系统报送、实体双锁、防火防爆、报警监控、人员培训等不能由本系统替代。 | 合规/🔒 |

## 六、当前上线前必须完成的线下工作

1. 由本单位 EHS/负责人逐一确认真实库位类型、允许储存组、物理防护和最大存量，再录入系统；系统的通用兼容矩阵不能替代 SDS 和现场储存设计。
2. 为现有化学品补录来源单位、交接凭证、供应商 SDS、目录复核结果和合规库位；历史数据默认保持隔离或禁止领用，系统不会自动猜测。
3. 与合作高校书面确认谁是实际购买、持有和公安报送主体，并约定交接时必须提供哪些许可/备案或领用凭证。
4. 为危废设置专用暂存库位，确定本地区国家危险废物信息系统操作人及有资质承运/处置单位；本系统登记联单号，但不替代国家系统开单。
5. 建立至少覆盖数据库、SDS、交接凭证、公安/许可凭证和危废联单的备份与保存制度，并按法规或更严格的单位制度确定保存年限。

## 七、这份底稿中已纠正的三个关键问题

1. 原文引用的 GB 15603《常用化学危险品贮存通则》是 1995 版旧标准，已被 **GB 15603-2022《危险化学品仓库储存通则》全部代替**。
2. 截至本核验日，《中华人民共和国危险化学品安全法》已经施行，不能再只用国务院令第 591 号作为上位依据。
3. “剧毒、易制爆、一类易制毒全部法定双人双锁”的概括不准确。系统改为“明确触发原因 + 可按单位制度加严”，其中盐酸属于第三类易制毒，不能仅因该身份自动判为国家层面双人双锁。

## 八、系统能力的法律边界

本系统可以落实账号权限、来源交接、库位兼容性校验、出入库台账、双人电子确认、SDS 快速调取、危废内部台账和审计导出，但**不能单独证明实验室已经合规**。合作高校采购安排不当然免除实验室作为实际接收、储存或使用单位可能承担的其他责任；专用储存场所、分隔柜、防火防爆、监控报警、实体双锁、人员培训、许可/备案责任划分、公安系统报送、危险废物国家系统电子联单等，必须由合作双方 EHS/负责人结合所在地监管要求书面确认并保留外部凭证。
