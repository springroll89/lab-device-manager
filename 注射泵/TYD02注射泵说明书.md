## 注射泵介绍

实验室注射泵是一种通过机械机构推动注射器传输液体的智能化机械装置,可应用于广泛的实验室及工业环境。工作时,步进电机带动丝杠将旋转运动变成直线运动,推动注射器的活塞进行注射输液,从而能够精确、均匀、持续地输送液体,实现高精度、平稳无脉动的液体传输。

## 简介

本系列产品可适配多种规格的注射器,根据需求选择不同的工作模式。产品采用 5 寸高分辨彩色液晶显示,触摸屏操作方便快速设置参数,双色指示灯清晰指示当前工作状态,且内置多种注射器厂商和规格方便选取,预存多组数据适应不同实验流量的要求,高精度控制,并有保护结构和堵车报警机制。产品支持外部信号控制启停,内置 RS-485 通讯,支持 Modbus 协议,塑料外壳,宽范围电源输入,适应各种实验场合。

## 操作说明

### 准备工作

- 打开外包装,对照装箱单检查所有配件是否有误或损坏,发现问题及时与厂家或代理商联系。
- 认真阅读使用说明书,并放在手边或固定地点收藏,以便随时查阅。
- 将泵放置在水平桌面上,后部距离障碍物保持 20 厘米以上的距离。
- ⚠️ 泵的位置须保证设备在用时方便使用断开装置。
- ⚠️ 请使用与机器铭牌上一致的电源,否则将损害设备!

### 注射器安装(以 TYD02 单通道为例)

1. 按住释放钮(1),移动滑块(2)到接近注射器长度的位置。
2. 松开锁定螺母(4)(7),调节固定托架(3)(6)的位置。
3. 将注射器放入右侧固定座凹槽里,同时将注射器推杆尾翼卡入固定托架(3),注射器针筒护翼卡入固定托架(6)。
4. 上紧锁定螺母(4)(7)。
5. 用内六角扳手调整限位块(8)的位置,防止过度推进损坏注射器。

### 电源连接

将随机附带的电源线插入驱动器后部的电源插口。

> ⚠️ **小心:** 确保所有的供电电线与设备功率相匹配。

## 操作向导(流程)

```
选择注射器厂商
   ↓
厂商是否在列表中?
   ├─ 是 → 选择注射器厂家 → 选择注射器规格 ┐
   └─ 否 → 选择 Custom → 输入注射器规格 ──┤
                                          ↓
                                     选择工作模式
                                          ↓
                                 是否延时或循环?
                                  ├─ 是 → 设置延时或次数 ┐
                                  └─ 否 ─────────────────┤
                                                         ↓
                                                     设定液量
                                                         ↓
                                                     设定流速
                                                         ↓
                                                     启动运行
```

### 1. 选择注射器

在主界面点击"设置·注射器",选择品牌;无品牌则选 Custom 并输入正确的注射器内径与规格,点击确定返回主界面。

### 2. 选择工作模式

点击主界面工作模式方块,选择要运行的工作模式。

### 3. 设定液量和流速

- 设定要注射的液量,点击液量值输入数值,点击液量单位在 **nL / uL / mL** 之间切换。
- 设置注入或抽取流速,点击流速值输入数值,点击单位在 **nL/min、uL/min、mL/min** 之间切换。

### 4. 开始运行

- 按启动键 ▶❚❚ 开始运行,绿色指示灯亮;运行结束红色指示灯亮。
- 运行中按暂停键 ▶❚❚ 暂停,绿灯闪烁;再按启动键继续未完成过程;按停止键 ■ 终止本次过程,红灯亮,参数复位。
- 运行中若推动块接触限位块或受外力阻挡,注射泵报警、红灯闪烁。按启动键 ▶❚❚ 解除警报继续运行,按停止键 ■ 结束运动过程。

### 过程运动示意

```
启动 → 运行过程 →（仅注入 / 仅抽取 / 注入→间隔延时→抽取 / 抽取→间隔延时→注入）
                              ↓
                        是否循环?
                          ├─ 是 → 间隔延时 → 回到运行过程
                          └─ 否 → 停止
```

## 多组数据存储和调用

### 数据存储

主界面先选择工作模式,再点击"配方"图标进入配方选择界面。通过选择配方一/配方二/配方三确定保存哪一组配方数据(系统初始化为配方一),然后进行液量和流速的设定,点击确定即保存。重复步骤可保存其他两组数据。

### 数据调用

## 流量校正

通过天平或量筒对实际传输的液体称量,完成对**自定义注射器**流量的校正。

### 操作步骤

1. 将注射器安装好,准备好适合的天平或量筒、量杯。
2. 在主界面设置为自定义注射器,并输入自定义注射器的内径和规格。
3. 在停机状态下,按快退键 ◀◀ 让注射器充满液体。
4. 按系统设置图标进入系统参数,选择"校正向导"图标。
5. 进入校正向导界面,系统显示当前注射器要校正的流量和液量(流速=传输液体速度,液量=传输液体体积)。两个数值和单位都可点击修改,再点"下一步"进入测试界面;点"返回"则退出校正向导。
   - ⚠️ 注意:为保证测试精度,液量值不要小于系统推荐的数值。
6. 测试界面:可进行多次测试并输入数据(测试1/测试2/测试3)。
   - 准备好量筒或烧杯,确认注射器内已充满液体,按一下启动键 ▶❚❚,注射器开始向外传输液体,传输完成后自动停止,用天平或量筒称量液体并记录数值。可重复称量多次,将数值填入测试1/2/3,注意单位是否正确,然后点"下一步"进入校正计算界面。
   - 提示:测试过程中如有意外发生,可按停止键 ■ 中止测试,再按启动键 ▶❚❚ 重新测试。
7. 校正计算:可输入 1 组或多组数据,系统自动求平均值并计算校正系数,显示原有系数参考。界面显示平均液量、校正系数、参数系数、系数。
   - 没问题则按"完成",系统保存新系数;按"上一步"重新测试;按"返回"不保存,返回系统参数界面。
   - 若没有输入数据,显示"无有效数据",请点击上一步重新测试。

## 外控模式

由外部信号控制启停和方向,**面板按钮不起作用**。在切断电源状态下,按接线图接好电路,将 DB15 接口连接到泵的背部接口上。

### 接线方式

- **连接外部 DC24V 电源(图41):** 用到 DB15 引脚 4(VCC_W)、6(CW_IN)、8(COM)、13(RS_IN);外部接 CW_W、RS_W 开关和 DC24V 电源(VCC_W / COM)。
- **连接内部 DC24V 电源(图42):** 用到引脚 10(+24V)、11(GND)、6(CW_IN)、13(RS_IN);外接 CW_W、RS_W 开关。

### 操作步骤

1. 打开电源开关,屏幕显示主控界面。
2. 设置运动控制的参数。
3. 在**仅注入、仅抽取、抽取/注入、注入/抽取**模式下:闭合一下外部 RS_IN 开关,注射泵开始运行;再闭合一下 RS_IN 开关,注射泵终止运行。
4. 在**连续模式·脉冲控制**时:闭合一下 RS_IN 开关,注射泵开始运行;再闭合一下,终止运行。
5. 在**连续模式·电平控制**时:始终闭合 RS_IN 开关,注射泵运行;断开 RS_IN 停止运行。断开 CW_IN 开关为注入方向,始终闭合 CW_IN 为抽取方向。

> ⚠️ 三条"小心"注意事项同"外控接口说明"(信号范围、低压隔离、保护线套)。

## 设备配网(Wi-Fi 定制版功能)

### 1. 配网准备

1. **下载 App:** 在应用商店搜索"雷弗云泵",或用手机浏览器扫描二维码下载安装。
   - 安卓国内:应用宝、华为、VIVO、OPPO、小米
   - 安卓国外:Google
   - iOS:苹果 App Store
2. **新用户注册及登录:** 安装完成后进入 App,按提示完成注册并登录。
3. 进入 App 后会有蓝牙权限、访问地理位置权限的授权申请,请按提示允许使用。
4. 确保手机已连接支持 **2.4G** 频段的 WiFi 网络。
5. 确保手机、设备、路由器三者靠近。

### 2. 进行配网

1. **使设备进入待配网状态:** 在任意工作模式主界面下,长按停止键 5 秒后松开,等至屏幕 Wi-Fi 状态图标开始闪烁且发出"滴"的一声,设备即进入时长 3 分钟的待配网状态。
2. 打开"雷弗云泵"App,进入首页,点击右上角"+"号,选择【添加设备】,进入添加设备页面,此时应能自动搜索到待配网设备,点击【添加】并按 App 提示完成添加。
3. 添加成功后即可使用 App 对驱动器进行控制。

### 配网失败排查

- 确认设备是否处于配网状态(WiFi 状态图标快速闪烁,每秒 3 次)。
- 确认手机是否打开蓝牙、地理位置权限,并授权给 App。
- 确认网络环境是否通畅,使手机、设备、WiFi 设备尽量靠近。
- 确认 WiFi 密码输入是否正确。
- 确认 WiFi 连接的是否是 2.4G 频段,否则改为 2.4G 频段网络。
- 以上确定后再次重试,仍不行请联系我们。
