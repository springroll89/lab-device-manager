Puricore 实验系统 · Windows 11 64 位离线部署包
================================================

安装前
------
1. 先用 Windows Defender 扫描整个 U 盘。
2. 确认电脑用网线连接实验室设备网络。
3. 如果旧版 Puricore 正在运行，先双击桌面的“停止Puricore实验系统”。

首次安装或升级
--------------
1. 打开 U 盘中的 Puricore-Win11-x64-offline 文件夹。
2. 双击“一键安装或升级.bat”。
3. Windows 询问是否允许更改设备时，选择“是”。
4. 安装器会先自动校验 U 盘文件，校验失败会停止安装。
5. 等待窗口显示“安装或升级完成”。安装过程不需要互联网。
6. 双击桌面的“Puricore Start”。

安装位置与数据
--------------
- 程序安装在 C:\PuricoreLab。
- 数据库、账号、配置和日志位于 C:\PuricoreLab\app\data。
- 每次升级前会自动备份数据和 config.local.toml 到 C:\PuricoreLab\backups。
- 上一个程序版本保留在 C:\PuricoreLab\app.previous，便于人工回滚。

首次登录
--------
- 初始账号：admin
- 初始密码：admin
- 首次登录后系统会强制修改密码。

访问地址
--------
- 主机本机：http://127.0.0.1:7800
- 平板/其他电脑：http://主机局域网IP:7800
- 启动窗口会列出可用的局域网地址。

现场设备自动发现
----------------
- 系统扫描 192.168.1.125、192.168.1.126、192.168.1.127 三台 UT-6804 的 1～4 号串口。
- 只有收到可验证仪器数据的端口才显示设备；空端口不显示，设备断开超过 15 秒后从当前列表隐藏。
- 本机 USB / 串口设备也会自动扫描，不需要预先写入占位设备。
- 第一阶段不会自动修改 UT-6804 串口参数。端口必须先按仪器设置为正确的 RS232/RS485、波特率和校验位。
- 已验证参数：LVDV-2T 为 RS232 / 9600 8N1；TYD02 为 RS485 / 9600 8E1 / 地址 1；HMS-C 为 RS485 / 9600 8N1 / 地址 1。

实验室主机网络配置
--------------------
- 有线网卡 IPv4：192.168.1.11
- 子网掩码：255.255.255.0（前缀长度 24）
- 默认网关、DNS：留空
- Windows 网络类型：专用网络

已安装主机更新现场配置
----------------------------
1. 把最新离线包复制到 U 盘。
2. 在联想 PC 上双击“更新实验室设备配置.bat”。
3. 工具会先停止系统、备份旧配置、写入新配置，然后重新启动系统。
4. 该操作不会删除数据库、账号或实验记录。

从 Mac 导入实验室数据
----------------------
1. 在 Mac 项目根目录双击“导出实验室数据.command”。
2. 把桌面生成的 puricore-data-transfer.zip 复制到本离线部署文件夹，与“导入Mac实验室数据.bat”放在同一层。
3. 在联想 PC 上双击“导入Mac实验室数据.bat”。
4. 工具会校验数据包、停止系统、备份 PC 原数据库、导入库存/账号/实验记录，然后重新启动系统。
5. 导入不会覆盖 Windows 主机自己的会话密钥；原数据库备份位于 C:\PuricoreLab\backups。

如需修改配置
------------
优先使用离线包里的“更新实验室设备配置.bat”。如需人工修改，编辑 C:\PuricoreLab\app\config.local.toml，然后停止并重新启动系统。

故障排查
--------
- 安装日志：U 盘部署目录中的 install.log
- 启动输出：C:\PuricoreLab\app\data\puricore-windows.out.log
- 启动错误：C:\PuricoreLab\app\data\puricore-windows.error.log
- 不要删除 data 文件夹；其中包含数据库、账号和会话密钥。
- 桌面上的“Puricore Stop”用于停止系统服务。
