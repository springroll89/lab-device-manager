## 五、准备工作

1. 使用 NDJ / SNB / LVDV 系列粘度计,将被测试样倒入直径不小于 **70mm** 的圆形平底容器中;使用 RVDV / HADV / HBDV 系列粘度计,装样容器直径不小于 **100mm**,容器高度不低于 **120mm**。
2. 将转子保护架安装在仪器下方罩壳上。(安装方法:仪器下方罩壳后侧有螺孔用于固定转子保护架)
3. 选择好适用的转子,按顺时针旋拧至下方转轴接头上。
4. 拧动升降旋钮使仪器缓缓下降,将转子浸入样品内且液面标志位(转子杆上的凹槽或凸线)与被测液面保持平齐。
5. 再次检查仪器前方水平仪是否在水平状态。

> ⚠️ **注意事项:**
> - 装卸转子时切勿向下或横向拨动转轴接头,以免内部结构受损。
> - 测试过程中环境温度尽量恒定,以保证测量值的稳定、准确。

## 六、仪器操作界面说明及操作方法(除 STM-2T)

**界面/接口(后视图)包含:** 显示屏、温度传感器接口、电源适配器接口、打印机接口、USB 接口、主机连接孔、水平仪、电源开关等。

以 **LVDV-1T** 机型为例:开机后仪器首先显示初始界面,等待 3 秒钟后自动进入主菜单页面(Fig.5),主菜单共有 4 个选择条。开机待粘度计初始化后,显示界面信息。

**主菜单(Fig.5)选项:**

| 菜单项 | 说明 |
|---|---|
| 粘度测试 | 用于粘度测试的参数设置,粘度等相关数据的测量与显示 |
| 已存条件测试 | 将以往已保的测试条件调出,直接用于粘度测试 |
| 管理测试数据 | 已经保存粘度测试数据的删除及 U 盘导出管理(仅限 DV1T 和 DV2T 型号含 U 盘导出功能) |

> 主菜单页眉显示:时间、日期、当前温度;底部标识 "LVDV-1T 旋转粘度计 / 上海方瑞仪器有限公司"。

### 1、粘度测试

#### 1.1 进入界面

点击"粘度测试"进入粘度测试界面(Fig.6)。

#### 1.2 参数设置

在粘度测试前要先设定好适合被测样品的测试参数(Fig.6)。

| 参数 | 类型 | 说明 |
|---|---|---|
| 样品名称 | 必填(可默认) | 样品名未设置时,默认为测试时年月日加时间节点 |
| 转子 | 必填 | 通过数值上下箭头 ▲▼ 选择(如 R2 #) |
| 转速 | 必填 | 通过 ▲▼ 选择(如 50 rpm) |
| 结束条件 | 选填 | 时:分:秒(如 0:5:0) |
| 样品密度 | 选填 | 输入被测样品密度值,便于计算运动粘度 |
| 量程 | 显示项 | 当前转子和转速下能测试到的最大粘度值(如 800 cp) |

其余参数都是点击参数值后使用虚拟键盘输入。

> **例:** 如已知被测样品粘度值约为 500 mpa.s,则可选择下列组合:**R2、50RPM**。

界面按键:**清除 / 保存 / 运行**。"保存"可将参数保存内置储存中,下次测试可通过"已存条件测试"直接调用;"运行"开始测试。

#### 1.3 开始测试(Fig.7)

点击"运行"开始测试,界面切换至测试界面(Fig.7),实时显示:

- **粘度:** 被测样品的粘度值(若测试时显示 ERROR,表示超出量程,需更换更大量程)
- **温度:** 温度传感器测得的温度值(需选配温度传感器才能显示;未插入显示 0.0℃)
- **转子:** 当前所选转子号
- **转速:** 当前所选转速(粘度计转速可无级调整,即不停止运转情况下改变转速)
- **剪切速率:** 当前测试条件下的剪切速率值
- **剪切应力:** 当前的剪切应力值
- **条状趋势栏:** 扭矩趋势栏刻度代表当前扭矩百分比,两端红色虚线处分别代表 10% 和 90%

#### 1.4 坐标显示(Fig.8)

测试时点击"坐标",显示界面会从列表显示变为坐标系显示状态(Fig.8),曲线显示粘度随时间变化。如需返回列表界面,点击左上角主页图标或点击"列表"按键。

#### 1.5 更多(Fig.9)

测试时点击"更多",显示之前的可选参数;如测试前未设置则显示数据为零。

- **动力粘度:** 此旋转粘度计测得的粘度值
- **结束条件:** 设定一个时间段,从开始测试时,到达该时间后测试自动停止。此时数据依然停留在测试界面,意义等同于定时测量粘度值。
- **剩余:** 剩余结束测试时间
- **密度:** 测试前填入的被测样品的密度,用以换算运动粘度值
- **运动粘度:** 被测样品的运动粘度值,等同于动力粘度值除以密度(如 100.0 mm2/s)

#### 1.6 结束测试(Fig.10)

完成测试后点击"停止",进入测试数据界面(Fig.10);点击"保存"进入保存预览界面,点击"确认"可将测试记录储存到仪器内存中,点击"打印"通过连接外置打印机能将数据打印出。

> 保存预览界面汇总:粘度、温度、扭矩、转子、转速、剪切速率、剪切应力、密度、运动粘度、测试时间、日期等。

#### 1.8 自动扫描(Fig.11)

该功能可为操作者提供最佳的转子、转速组合信息。点击参数设置界面右上角的"自动扫描",界面切换至扫描界面(Fig.11),设定任一转子,同时安装上该型号转子,点击"确定"开始扫描。

- "扫描结果"一栏中开始显示扫描状态。
- 当扫描结果满足测试要求时,"扫描结果"处显示"适用",点击"应用"直接把扫描结果应用到测试参数中。
- 如扫描结果无法满足测试要求时,"扫描结果"处显示"请更换小号转子"或"请更换大号转子",此时按照屏幕提示操作即可。

> 扫描界面显示:转子、转速、扭矩(%)、扫描结果。按键:应用 / 确定 / 停止。

### 2、查看、调用测试条件记录(Fig.12)

点击"已存条件测试"后,屏幕上会显示已存储的测试记录(Fig.12),选择所需的测试条件。点击"编辑",出现垃圾桶图标可以删除已存测试条件。

### 3、管理测试记录(Fig.13 / Fig.14)

点击"管理测试数据"后,屏幕上会显示已存储的测试记录(Fig.13),选择所需的记录即可查看、删除、U 盘导出该项记录。

- 点击垃圾桶图标可以删除所选的测试数据;
- 点击 U 盘图标可将数据导出至 U 盘(Fig.14),会弹出"是否导出?"确认框(取消 / 确认)。

### 4、设置(Fig.15–Fig.19)

仪器的常规设置,时间和日期及操作介绍说明等(Fig.15)。设置菜单:**日期/时间设置、背光调节、温度校准、说明书、恢复出厂设置**。

#### 4.1 时间、日期的设定(Fig.16)

点击"日期/时间设置",直接对日期、时间栏中的数值进行调整。(日期:年/月/日;时间:时/分/秒)

#### 4.2 背光调节(Fig.17)

点击"背光调节",通过指示条两端的"-""+"或直接拖动圆形调节钮进行屏幕亮度的调节。

## 七、STM-2T 斯托默粘度计使用操作介绍

### 安装(Fig.20 / Fig.21 / Fig.22 / Fig.23)

1. 从包装箱依次取出底座、升降立柱、粘度计主机、主机连接杆、电源适配器等部件(Fig.20)。
2. 将升降立柱插入底座孔后用螺帽并紧。(注意:升降旋钮置于右侧)
3. 旋动升降旋钮,调节到合适的升降松紧度,以主机不会自动下滑、且升降时阻尼手感适中为宜;如太松或太紧,可通过升降滑块前方的一字螺钉进行调节。
4. 再将主机连接杆上的螺钉拧下,然后铣平面往下插入主机后下方的安装孔中,用拧下的内六角螺钉将主机连接杆与主机底板连接并紧固。
5. 再将装好连接杆的主机插入升降滑块的安装孔中,摆正后拧紧固定旋钮。
6. 通过调节底座下方的三个水平脚,使仪器前方的水平仪气泡处于黑圈中(Fig.21)。
7. 将转子及转子套管从包装盒内取出,并用紧固螺钉固定转子。注意:紧固螺钉应固定在转子杆的扁口上,将转子套管另一端用紧固螺钉固定在中心轴上。
8. 在料筒内倒入适量的被测样品。拧动升降旋钮使仪器缓缓下降,将转子浸入样品内且转子上的液面标志位(转子杆上的凹槽或凸线)与被测液面保持平齐(Fig.22)。再次检查仪器前方水平仪是否在水平状态(Fig.23)。

> 部件标注(Fig.22):下轴套、中心轴、紧固螺钉、转子套管、K10 转子、料筒等。
> 部件标注(Fig.23):主机、丝杆罩、下罩壳、转子管、转子、套管、底座等。

### STM-2T 斯托默粘度计测试(Fig.24–Fig.26)

点击"粘度测试"进入粘度测试界面(Fig.24),首先输入样品名(中/英文、数字皆可,默认为日期和时间),然后设置测量时间(时-分-秒),设定完成后点击"运行"即可开始测试粘度。

**开始测试:** 进入粘度测量界面(Fig.25),可直接读取所测得的该样品的各种数值。测试过程中点击"坐标"会进入坐标曲线界面(Fig.26),数据以曲线形式在坐标系中显示。测试完成后点击"停止"则完成测试,或运行到设定测量时间结束时自动停止测试。

测试结束后可对所测得的数据以及坐标曲线进行保存、打印,以供传阅或记录。

> 如样品的粘度值过大,仪器会有溢出警告,此时 KU、CP、负载值都会显示 ERROR,此情况则说明该测试样品的粘度值已经超出了本仪器的最大量程。

**STM-2T 测量界面显示参数:**

| 参数 | 示例值 | 单位 |
|---|---|---|
| KU | 141 | KU |
| cp | 5250 | cp |
| 负荷 | 1099 | g |
| 温度 | 25 | ℃ |
| 结束时间 | 00:03:00 | — |

- **查看、调用测试条件记录:** 点击"已存条件测试"后,屏幕上会显示已存储的测试记录(Fig.27),选择所需的测试条件。点击"编辑",出现垃圾桶图标可以删除已存测试条件。

## 八、注意事项

1. 由于粘度是温度的函数,仪器在常温下工作时,温度波动应控制在 **±0.3℃**,否则会影响测量的准确度,必要时可选配恒温浴槽控制温度。
2. 保持转子表面的清洁,转子请勿碰撞。
3. 由于游丝具有一定的线性区,测量时请注意扭矩百分比,该数值应处于 **10%–90%** 之间。当扭矩百分比的数值过高时,扭矩及粘度会显示溢出符号"ERROR",此时应更换转子或改变转速,否则会影响测量的准确度。
   > **例如:** 用 LVDV-1T 型测试样品用"一号转子、每分钟 60 转"转速组合测试,扭矩百分显示"ERROR",那应降低转速。如当已降低至"每分钟 1.5 转"时,扭矩百分仍显示"ERROR",那应改选用小点的转子(表面积小)测行测试。如出现测试的样品在同种转子情况下,不同转速时的扭矩百分比的数值都处于 10%–90% 之间,那取扭矩偏大的值为准。其它型号测试以此类推。
4. 装卸转子时应小心操作,将万向接头微向上抬起,不可用力过大。不要让转子横向受力,切不可将转子向下拉,以免损坏轴尖。因转子与万向接头的连接为**左螺纹**,在装卸转子时请切记旋转方向(按图 Fig.30 所示),以免损坏万向接头。
5. 仪器下降时要缓慢,最好用手托住,避免震动损坏轴心。
6. 仪器在运输或搬动时,转子连接头应套上塑料保护帽。
7. 悬浊液、乳浊液,以及高聚物和其他高粘度液体中很多都是"非牛顿"液体,其表观粘度值随着切变速度和时间的变化而变化,故在不同的转子、转速和时间下测定,其结果不一致属正常情况(如测量非牛顿流体即使在相同转子、不同转速情况下,其结果也会有偏差)。这都属于流体的性质所决定,并非仪器测试有问题。
8. 关于 **PT100 测温探针**安装介绍,如图 Fig.29 所示。(此配件为另选配件,标配不包含)

> 转子装卸旋转方向示意(Fig.30):安装转子按顺时针方向,拆卸转子按逆时针方向。
